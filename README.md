# 🐥 Flappy Bird - Classic Retro Recreation

A faithful, responsive HTML5 Canvas recreation of the legendary Flappy Bird arcade game.

## 🎮 Play Online
👉 **Live Game URL:** [https://theinfinityhub000s-hub.github.io/flappy-bird/](https://theinfinityhub000s-hub.github.io/flappy-bird/)

---

## ✨ Features
- **Authentic Physics & Feel:** Precise flap impulse, gravity, smooth rotational tilt, and tuned pipe hitboxes.
- **Pure Web Audio Synthesizer:** Real-time synthesized retro 8-bit sound effects (jump, score chime, collision crunch, fall thud, swoosh) without external audio assets or latency.
- **Parallax Background:** Multi-layer scrolling background featuring clouds, skyline, and animated striped dirt ground.
- **Day / Night Mode:** Toggle between crisp cyan daytime and midnight starry themes.
- **Medal & High Score System:**
  - 🥉 Bronze Medal: 10+ points
  - 🥈 Silver Medal: 20+ points
  - 🥇 Gold Medal: 30+ points
  - 💎 Platinum Medal: 40+ points
  - High scores automatically saved to local storage.
- **Arcade Polish:** Screen shake, death flash, jump dust particles, "+1" popup scores.
- **Cross-Platform:** Works on desktop keyboards, mice, and mobile touchscreens.

---

## 🕹️ Controls
- **Flap / Jump:** `Spacebar` / `Up Arrow` / `W` / Left Mouse Click / Mobile Screen Tap
- **Pause / Resume:** `P` key or pause icon (⏸️)
- **Mute / Unmute:** `M` key or sound icon (🔊)
- **Day / Night Theme:** Moon/Sun icon (☀️/🌙)
